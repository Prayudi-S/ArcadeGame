# mesin-bahts

Semua aturan kerja ada di `AGENTS.md` di folder ini. Baca seluruhnya sebelum mulai,
lalu jalankan perintah dari folder skill ini:

- Daftar perintah: `python3 mesin/bahts.py`
- Daftar tanda naskah: `python3 mesin/bahts.py tanda`
- Cek kesiapan: `python3 mesin/bahts.py periksa`

Dokumen pendukung: `dok/` (mutamad, takhrij, uji-riset), contoh naskah di `contoh/`.
